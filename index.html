Questions

Short answers. The app is small, so the FAQ is too.

Does it close apps on its own?

Never. Every Pause or Quit is one click by you. Breathe only watches.

What does Pause do?

It asks the app to quit politely, like ⌘Q, and reopens it after 10, 30 or 60 minutes. You pick.

Is it a "RAM cleaner"?

No. macOS already manages memory well. What helps is pausing the one app that is heavy, and Breathe tells you which.

Does it send anything anywhere?

No account, no network, no analytics. Readings live in memory and are gone when you quit.

What about macOS processes?

Listed with their memory so you understand them, with no button. Breathe won't touch them.

What does it cost?

Nothing. The Mac version is signed and notarized by Apple, outside the App Store.

Is there a Windows version?

Yes, an early build. It is built to show the same face in the tray, list the heaviest apps and close one politely. No Pause. Nobody has run it on a real PC yet, so treat it as a test. It needs Microsoft's free .NET 8 Desktop Runtime, and Windows shows a blue warning because it is not signed.

Does it run on Intel Macs?

Not yet. The current download is built for Apple silicon.

Give your Mac some room

Open the DMG, drag Breathe to Applications, click the face in your menu bar.
